### 按小时计费，删掉服务器就停止扣费了吗？

是的。机器存在多久就按小时计费多久，销毁后停止产生这台机器的费用。传统云服务器线每月按约 672 小时封顶，VX1 按实际小时计费、没有月度上限。快照、自动备份、块存储这类附加项按各自价格另行计费。

超出套餐的部分按 $0.01/GB 计费。同机房实例之间的内网流量不收费。
